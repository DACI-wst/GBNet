## 📖 Introduction
Appearance-based gaze estimation requires effective supervision strategies to represent continuous gaze directions with highly non-uniform label distributions. 

To address the limitations of traditional uniform-width angular discretization, we propose a training-distribution-aware discretization framework, termed **Gaussian-guided Binning Network (GBNet)**. 
- GBNet constructs adaptive non-uniform bin boundaries through Gaussian quantile transformation.
- It allocates finer angular resolution to high-density gaze regions and broader intervals to low-density regions.
- Extensive experiments on Gaze360, MPIIFaceGaze, and EyeDiap demonstrate that GBNet significantly outperforms existing approaches.
